# Unity Tanks

This is an older Unity project that I worked on during university while learning the basics of game development with Unity.

The project is based on the Unity Tanks tutorial. As part of the university assignment, I had to extend the original project with additional gameplay features.

My main additions were:

- Health pack
- Explosion mechanic
- Speed boost

The project helped me practice working with gameplay mechanics, player interactions, effects, pickups, and basic scripting in Unity.

The project was later updated to a newer Unity LTS version!
